# 🎯 RegularsDetector — Детектор постоянников

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Распознаёт постоянных покупателей: при новом заказе вы мгновенно видите
**«👑 buyer1 покупает у вас 5-й раз! Всего потрачено: 850 ₽»** — и можете положить
бонус, написать личное спасибо или дать скидку. Постоянные клиенты — самая прибыльная
аудитория, не теряйте их.

## Возможности

- 👑 **Уведомление при заказе от постоянника** — N-я покупка, сумма заказа и сколько
  покупатель потратил у вас за всё время, ссылка на профиль.
- 📚 **База покупателей** по полной истории ваших продаж: число покупок, суммарные
  траты, дата последней покупки.
- 🔄 **Автообновление базы** (по умолчанию раз в 24 часа) + инкрементальное дополнение
  по каждому новому заказу между сканами + ручная кнопка «Обновить базу сейчас».
- 👑 **Топ покупателей** — рейтинг по числу покупок и суммам, клик открывает профиль
  покупателя на FunPay.
- 🎯 Настраиваемый порог «постоянника» (по умолчанию — со 2-й покупки).
- 💾 База хранится на диске (`storage/plugins/regulars_detector/db.json`), переживает рестарт.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-RegularsDetector/main/regulars_detector.py -O plugins/regulars_detector.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/regulars`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 👑 Топ покупателей | Рейтинг клиентов (покупки + суммы), клик → профиль на FunPay |
| 🔄 Обновить базу сейчас | Полный перескан истории продаж (в фоне, с уведомлением о завершении) |
| 🎯 Порог: 2 покупки | С какой покупки считать постоянным (2–100) |
| ⏱ Автообновление: 24 ч. | Период автоматического перескана (1–168 ч.) |

После установки нажмите «🔄 Обновить базу сейчас» — плагин просканирует историю
продаж и сразу начнёт узнавать старожил. При первом же новом заказе от постоянника
придёт уведомление 👑.

### Пример уведомления

```
👑 Постоянный покупатель!

buyer1 покупает у вас 5-й раз!

Заказ: #A1B2C3D4
Лот: Аккаунт Steam с играми
Сумма заказа: 150 ₽
Всего потрачено у вас: 900 ₽

💎 Самое время положить бонус или написать личное спасибо 😉
```

## Важно знать

- Учитываются заказы в статусах «оплачен» и «закрыт»; возвраты не учитываются.
- Полный скан ограничен 40 страницами истории (~2000 заказов) за проход — для очень
  старых аккаунтов база соберётся по наиболее свежей истории и будет уточняться
  инкрементально.
- Уведомления идут через тип «Прочие уведомления (плагины)».
- Плагин ничего не отправляет покупателям — только информирует вас.

## Состав репозитория

- `regulars_detector.py` — плагин (класть в `plugins/`).
- `tests_plugin_regulars.py` — тесты (33 проверки на моках: скан истории с пагинацией,
  агрегация, статусы заказов, инкремент, уведомления, топ, настройки). Запуск из корня
  FunPayCardinal:
  ```bash
  cp tests_plugin_regulars.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_regulars.py
  ```
